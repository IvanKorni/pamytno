# 010. Провайдер Claude

## Сценарий

В проде вопросы и карточки генерирует Claude. Включается переменными окружения:

```bash
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=...          # только из окружения, в репозиторий не попадает
AI_MODEL=claude-opus-5         # по умолчанию
```

## Правила и решения

- Официальный Anthropic Java SDK (`com.anthropic:anthropic-java`), без самописного HTTP.
- Модель по умолчанию — `claude-opus-5`; менять — `AI_MODEL`. Лимит ответа — `AI_MAX_TOKENS` (16000).
- Structured outputs: ответ ограничен JSON-схемой из records `QuestionsPayload` / `CardPayload`,
  свободный текст не парсится.
- `AI_EFFORT` (`low`…`max`) — рычаг цены/качества; пусто — значение API по умолчанию. Для массовой генерации
  вопросов стоит попробовать `medium`, сравнив качество на своих материалах.
- Перед чтением ответа проверяется `stop_reason`: `refusal` (отказ модели) и `max_tokens` (обрезанный ответ)
  превращаются в `AiGenerationException` → задача генерации получает `ERROR` с понятным сообщением.
- Серверный fallback при отказе включён по умолчанию (`anthropic-beta: server-side-fallback-2026-07-01`,
  `fallbacks: "default"`): если модель отказала по соображениям безопасности, сервер Anthropic сам повторит запрос
  на подходящей модели. Выключить — `AI_REFUSAL_FALLBACK=false`.
- Промпты на русском, модель пишет на языке материала. Материал пользователя передаётся внутри `<material>`
  и отделён от инструкций. В промпте: вопросы только по тексту фрагмента, цитата-источник дословно,
  ответ карточки — только по материалу, до 10 предложений.
- Повторы запросов при 429/5xx — встроенные в SDK (2 попытки по умолчанию). Ошибки API логируются без текста материала;
  в лог пишутся модель и число токенов ответа.

## Тесты

- Unit: `AnthropicAiProviderTest` — WireMock вместо Anthropic API: тело запроса (модель, `output_config.format`
  json_schema, `effort`, `fallbacks`, beta-заголовок, материал в `<material>`), разбор вопросов и карточки,
  `refusal` и `max_tokens`, HTTP 529.
- Реальный API в автотестах не вызывается (стоит денег); проверка вручную — запуск с `AI_PROVIDER=anthropic`.
