# 008. Генерация карточек

## Сценарий

После отбора вопросов пользователь нажимает «Создать карточки». По каждому одобренному вопросу AI составляет
карточку: вопрос на лицевой стороне, ответ на оборотной. Фронт опрашивает задачу, как в фиче 006.

## API

| Метод | Путь | Успех | Ошибки |
|---|---|---|---|
| POST | `/api/topics/{topicId}/cards/generate` | 202 `GenerationJobDto` | 401, 409 |
| GET | `/api/generation-jobs/{jobId}` | 200 `GenerationJobDto` | 401, 404 |

## Правила и решения

- Используются только вопросы в статусе `APPROVED`; после создания карточки вопрос переходит в `CARD_CREATED`,
  поэтому повторный запуск не дублирует карточки.
- LLM получает вопрос и контекст: цитату-источник вопроса и весь фрагмент единого текста, из которого она взята
  (разделитель `---`), если фрагмент отличается от цитаты.
- Жёсткого формата у карточки нет; рекомендуемый объём ответа — до ~10 предложений или пунктов (подсказка в промпте).
  Оформление — простая разметка (фича 018): выделение, списки, варианты ответа, код.
- Пустая лицевая сторона от модели заменяется текстом вопроса; пустой ответ — карточка не создаётся.
- Если пользователь отклонил вопрос, пока шла генерация, карточка по нему не создаётся.
- Каждая карточка публикует `FlashcardCreated(cardId, topicId, userId, front, back)` — модуль `learning`
  заводит по ней прогресс повторения.
- Одновременно по теме — одна генерация карточек (`GENERATION_IN_PROGRESS`).

## Ошибки

| Код | Когда |
|---|---|
| `NO_APPROVED_QUESTIONS` | в теме нет одобренных вопросов без карточек |
| `GENERATION_IN_PROGRESS` | генерация карточек по теме уже идёт |

## Тесты

- Unit: `FlashcardTest`, `CardContextBuilderTest`, `FlashcardWriterTest`, `CardGenerationServiceTest`,
  `CardGenerationWorkerTest`.
- Модульные: `CardGenerationModuleTest` — карточки только по одобренным вопросам, событие `FlashcardCreated`
  (через `CapturedEvents`), 409 без одобренных вопросов.
