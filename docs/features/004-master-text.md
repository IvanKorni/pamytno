# 004. Единый текст темы (Master Text)

## Сценарий

После обработки источников пользователь видит единый текст темы — все материалы подряд — и дальше
запускает по нему генерацию вопросов (модуль `deck`).

## API

| Метод | Путь | Успех | Ошибки |
|---|---|---|---|
| GET | `/api/topics/{topicId}/content` | 200 `{topicId, version, content, createdAt}` | 401, 404 |

## Правила и решения

- Текст = извлечённые тексты **готовых** источников в порядке добавления, разделённые пустой строкой.
- AI текст не сокращает и не переписывает; допустима только техническая очистка при извлечении (фича 003).
- Версии неизменяемы. Новая версия создаётся только если объединённый текст изменился
  (добавлен/удалён/обработан источник). Первая версия не создаётся, пока текст пустой.
- Если готовых источников не осталось, создаётся версия с пустым текстом — чтобы `deck` очистил фрагменты.
- Пересборка идёт под `SELECT ... FOR UPDATE` строки темы: параллельные обработки не создадут две одинаковые версии.
- Каждая новая версия публикует `TopicContentPrepared(topicId, userId, version, content)`.

## Ошибки

| Код | Когда |
|---|---|
| `TOPIC_NOT_FOUND` | тема чужая или не существует |
| `TOPIC_CONTENT_NOT_FOUND` | ещё нет ни одного обработанного источника |

## Тесты

- Unit: `MasterTextBuilderTest`, `TopicContentTest`, `TopicContentServiceTest`.
- Модульные: `TopicContentModuleTest` — 404 до обработки, событие `TopicContentPrepared` (через `CapturedEvents`),
  объединение источников и новая версия после удаления.
