# 012. Учебные сессии

## Сценарий

Пользователь начинает обучение по теме — фронт создаёт сессию, показывает карточки к повторению и передаёт
`sessionId` в каждый ответ (фича 013). В конце сессия завершается; по сессиям собирается статистика.

## API

| Метод | Путь | Успех | Ошибки |
|---|---|---|---|
| POST | `/api/topics/{topicId}/learning-sessions` | 201 | 401 |
| GET | `/api/learning-sessions/{sessionId}` | 200 | 401, 404 |
| POST | `/api/learning-sessions/{sessionId}/complete` | 200 | 401, 404 |

## Правила и решения

- `cardsTotal` — сколько карточек темы было к повторению в момент старта.
- `cardsRemembered` / `cardsForgotten` — ответы REMEMBER / FORGOT с этим `sessionId`; CONTINUE не считается.
- Завершённая сессия не принимает ответы (`LEARNING_SESSION_COMPLETED`); повторное завершение ничего не меняет.
- Модуль `learning` не знает о темах напрямую: сессию можно начать по любому `topicId`, но данные фильтруются
  по владельцу, поэтому по чужой теме в ней просто не будет карточек.

## Ошибки

| Код | Когда |
|---|---|
| `LEARNING_SESSION_NOT_FOUND` | сессии нет или она чужая |
| `LEARNING_SESSION_COMPLETED` | ответ в уже завершённой сессии |

## Тесты

- Unit: `LearningSessionTest` — счётчики ответов, завершение.
- Модульные: `LearningSessionModuleTest` — старт с числом карточек к повторению, завершение, чужая сессия 404.
