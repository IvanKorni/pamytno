# 009. Карточки: просмотр и редактирование

## Сценарий

Пользователь видит все карточки темы, открывает карточку с цитатой-источником, правит вопрос или ответ,
удаляет лишнюю карточку. AI-карточка никогда не неизменяема.

## API

| Метод | Путь | Успех | Ошибки |
|---|---|---|---|
| GET | `/api/topics/{topicId}/cards` | 200 `FlashcardDto[]` | 401 |
| GET | `/api/cards/{cardId}` | 200 `FlashcardDto` | 401, 404 |
| PATCH | `/api/cards/{cardId}` `{front?, back?}` | 200 `FlashcardDto` | 400, 401, 404 |
| DELETE | `/api/cards/{cardId}` | 204 | 401, 404 |

## Правила и решения

- PATCH меняет только переданные стороны; пустая строка отклоняется валидацией.
- Карточки идут в порядке создания (`seq`).
- Изменение публикует `FlashcardUpdated`, удаление — `FlashcardDeleted`: модуль `learning` держит у себя копию
  текста карточки для повторения и обновляет/удаляет её по этим событиям.
- Удаление карточки не возвращает вопрос в отбор: он остаётся `CARD_CREATED`, чтобы повторная генерация
  не воскресила удалённую карточку.

## Ошибки

| Код | Когда |
|---|---|
| `CARD_NOT_FOUND` | карточки нет или она чужая |
| `VALIDATION_FAILED` | пустая сторона карточки |

## Тесты

- Unit: `FlashcardTest` (правка сторон), `FlashcardCommandServiceTest` (события правки и удаления).
- Модульные: `FlashcardModuleTest` — список и карточка с цитатой, PATCH + `FlashcardUpdated`,
  удаление + `FlashcardDeleted`, изоляция пользователей.
