# 007. Отбор вопросов

## Сценарий

Фронт показывает сгенерированные вопросы с цитатами-источниками. Для каждого пользователь выбирает
«изучать» или «не изучать», может поправить формулировку или принять решение сразу по многим вопросам.
Карточки создаются только по одобренным вопросам (фича 008).

## API

| Метод | Путь | Успех | Ошибки |
|---|---|---|---|
| GET | `/api/topics/{topicId}/questions?status=APPROVED` | 200 | 401 |
| POST | `/api/questions/{questionId}/approve` | 200 | 401, 404, 409 |
| POST | `/api/questions/{questionId}/reject` | 200 | 401, 404, 409 |
| POST | `/api/questions/decisions` `{questionIds, decision}` | 200 | 400, 401, 404, 409 |
| PATCH | `/api/questions/{questionId}` `{text}` | 200 | 400, 401, 404, 409 |

## Правила и решения

- Статусы: `GENERATED → APPROVED / REJECTED` (решение можно менять) `→ CARD_CREATED` (окончательно).
- После создания карточки вопрос не меняется — правится карточка (`QUESTION_ALREADY_HAS_CARD`).
- Массовое решение — «всё или ничего»: если хоть один вопрос не найден или уже с карточкой, не меняется ни один.
  До 500 вопросов за запрос.
- Список темы чужому пользователю отдаётся пустым (данные фильтруются по владельцу).

## Ошибки

| Код | Когда |
|---|---|
| `QUESTION_NOT_FOUND` | вопроса нет или он чужой |
| `QUESTION_ALREADY_HAS_CARD` | по вопросу уже создана карточка |
| `VALIDATION_FAILED` | пустая формулировка, пустой список, неизвестное решение |

## Тесты

- Unit: `QuestionTest` (решения, правка, блокировка после карточки), `QuestionReviewServiceTest`
  (массовое решение, «всё или ничего»).
- Модульные: `QuestionReviewModuleTest` — approve/reject и фильтр, массовое решение, правка и валидация,
  изоляция пользователей.
