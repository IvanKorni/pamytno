# 018. Карточки с разметкой и задачи с вариантами ответа

## Сценарий

Пользователь загружает задачу с разбором — например, еженедельную задачу по распределённым системам: условие,
вопрос, варианты A–D, правильный ответ и объяснение. Раньше AI разбивал её на мелкие вопросы «почему…», сама задача
в колоду не попадала, а длинная карточка выводилась гигантским заголовком: варианты слипались в один абзац,
в ответе были видны `**` и ```` ``` ````.

Теперь:

1. Среди вопросов есть отдельный вопрос-задача: кратко условие, вопрос **жирным**, варианты — каждый с новой строки.
2. Карточка по нему: на лицевой стороне — условие и варианты, на оборотной — верный вариант **жирным**,
   почему он подходит и списком — почему не подходят остальные. Схема потока данных — блоком кода.
3. В режиме обучения короткий вопрос по-прежнему крупный, а длинный (задача) читается обычным текстом:
   варианты — плашками с буквой, ответ — абзацами, списками и кодом. На телефоне кнопки «Помню / Не помню»
   остаются закреплены внизу.
4. В списке карточек свёрнутая карточка показывает первую строку вопроса, раскрытая — варианты и ответ.
   Отбор вопросов (по одному и списком) тоже показывает разметку, а не сырые символы.

## API

Контракт не меняется: `front`, `back` и текст вопроса остаются строками. Разметка — соглашение между промптом AI
и фронтом.

## Разметка

Небольшое подмножество Markdown, которым модели и так оформляют ответы:

| Разметка | Как выглядит |
|---|---|
| пустая строка | новый абзац; одиночный перенос сохраняется внутри абзаца |
| `A. …` / `B) …` (латиница A–F или кириллица А–Е, от двух строк подряд) | варианты ответа с буквой-плашкой |
| `- …`, `* …`, `• …` | маркированный список |
| `1. …`, `2) …` | нумерованный список |
| ```` ``` ```` … ```` ``` ```` | блок кода или схемы; незакрытый блок идёт до конца текста |
| `**…**`, `` `…` `` | выделение и код внутри строки |

## Правила и решения

- Разметка разбирается в `shared/lib/richText.ts` и выводится `RichText` из React-элементов, без HTML:
  текст от AI не может внедрить свою разметку. Архитектурный тест `codeRules` запрещает `dangerouslySetInnerHTML`.
- Одна строка вида `A. …` — не варианты (например, инициалы «А. С. Пушкин»), а обычный абзац.
- Внутри заголовков и `<label>` (крупный вопрос, строка списка вопросов) допустима только строчная разметка —
  `RichInline`; абзацы и списки там — только в `RichText`.
- Вопрос считается коротким, если он в одну строку и не длиннее 140 символов: такой выводится заголовком,
  длиннее — обычным текстом слева.
- Правила оформления для AI — общие для всех провайдеров в `AiFormatRules` (`QUESTIONS`, `CARD`); Claude
  (`AnthropicPrompts`) и CLI-провайдер (`CliAiProvider`) подставляют их в свои промпты.
- Ответ карточки — до 10 предложений или пунктов списка. Модель иногда выделяет жирным ответ из одной фразы —
  это только стиль, на обучение не влияет.
- Ручная правка карточки (`EditCardModal`) принимает ту же разметку.

## Ошибки

Новых кодов ошибок нет.
