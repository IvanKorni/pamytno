# Frontend MVP

## Сценарий

Фронтенд закрывает путь из ТЗ: вход или регистрация → создание темы → добавление текста, списка слов, PDF или YouTube → polling обработки → единый текст → генерация вопросов → последовательный или списочный отбор → генерация карточек → обучение с «Помню» / «Не помню» → завершение сессии → dashboard и прогресс.

## Решения

- React Router разделяет dashboard, тему и вложенные экраны материалов, вопросов, карточек, обучения и прогресса.
- TanStack Query отвечает за запросы и polling; Zustand хранит только JWT-пользователя, очередь текущей сессии и toast.
- Frontend отображает `stage` и `nextReviewAt` от backend и не рассчитывает интервалы повторения.
- Забытая карточка возвращается в хвост текущей очереди только когда backend выставляет `returnToSession`.
- Интерфейс адаптирован под desktop и мобильную ширину; learning mode сохраняет крупную читаемую карточку.

## Проверки

- Unit: склонение слов и форматирование процентов.
- Module: API-клиент, заголовок авторизации и обработка 401.
- Integration: регистрация, создание темы и приём текста по HTTP; запускается при `VITE_PAMYTNO_INTEGRATION_URL`.
- `npm run check` — 4 теста проходят, один integration-тест пропускается без URL backend, production build проходит.
