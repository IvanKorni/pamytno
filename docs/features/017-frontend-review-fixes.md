# Исправления фронтенда после ревью

## Сценарий

Ревью фронтенд-MVP (016) нашло баги на основном пути пользователя. Каждое исправление — отдельный коммит
с тестом, который падал на старом коде.

## Обучение

- **Повторный вход не зависает.** Очередь сессии была в глобальном Zustand и переживала уход с экрана,
  а флаг готовности — нет: при возврате экран навсегда оставался на «Готовим карточки…».
  Теперь состояние сессии — локальный reducer экрана (`learningSession.ts`): ушёл с экрана — сессия закончилась,
  вернулся — начинается новая.
- **Карточки к повторению не берутся из кеша.** `fetchQuery` отдавал список 20 секунд, и новая сессия
  получала уже пройденные карточки. Backend не проверяет срок повторения, поэтому «Помню» по такой карточке
  продвигало её по этапам раньше времени. Список каждый раз загружается с backend.
- **Пустая сессия не создаётся.** Сначала загружаются карточки к повторению; если их нет — экран
  «Пока нечего повторять», запрос на старт сессии не отправляется.
- **Ошибка старта видна.** Раньше ошибка превращалась в пустое состояние; теперь — экран ошибки с повтором.
- **Одна сессия в StrictMode.** Старт защищён `ref`, двойной запуск эффекта в dev не создаёт вторую сессию.
- **Режим обучения — отдельный экран** `/topics/:topicId/learn` без шапки темы: на телефоне кнопки
  «Помню / Не помню» больше не уходят за край экрана.
- Этап показывается как `stage + 1` из 6 (backend считает этапы с нуля), вместо счётчика «1 / N»,
  который путался из-за возвращённых карточек, — «Осталось N карточек».
- Итоги сессии ведут «К теме» или «На обзор»; кнопка «Закрыть», которая ничего не делала, убрана.

## Вопросы и генерация

- **Упавшая генерация не держит экран.** При `ERROR` задача не сбрасывалась, опрос шёл вечно, а экран
  оставался в «Анализируем материалы…» с заблокированной кнопкой. Теперь опрос останавливается на `READY`
  и `ERROR` (`jobPollInterval`), ошибка показывается, генерацию можно запустить снова.
- **Генерация переживает уход с вкладки.** Идущая задача запоминается в sessionStorage по теме и виду
  (`jobStorage`); после возврата или перезагрузки экран продолжает опрос, а не предлагает запустить
  генерацию заново и не получает `GENERATION_IN_PROGRESS`.
- **Баннер «карточки созданы» — только после создания.** Раньше он появлялся после одобрения первого вопроса,
  когда карточек ещё нет, и пропадал, когда они появлялись. Теперь он показывает `itemsCreated`
  завершённой задачи генерации карточек.
- **«Снять выбор» только снимает выбор.** Раньше кнопка отклоняла выбранные вопросы на backend.
  Отклонение — отдельная кнопка «Не изучать выбранные».
- **В выборе остаются только новые вопросы** (`pendingSelection`): вопрос, отклонённый по одному после того,
  как его отметили в списке, больше не одобряется при «Создать карточки» и не считается дважды.
- **Одно решение на вопрос.** Кнопки блокируются, пока решение отправляется, а ответ backend сразу
  подменяет вопрос в списке — двойной клик больше не шлёт два решения.
- Счётчик «N / M» считает просмотренные вопросы, а не всегда «1 / M»; ошибка исчезает при следующей попытке;
  кнопка «Создать вопросы» больше не дублируется; после создания карточек перечитываются вопросы,
  карточки, прогресс темы и dashboard.
- **Временная ошибка опроса не теряет задачу.** Задача забывается только при 404; после сетевой ошибки или 5xx
  опрос продолжается, а экран остаётся в «Анализируем материалы…» — повторный запуск не упрётся в
  `GENERATION_IN_PROGRESS`.
- Кнопки «сгенерировать ещё» нет намеренно: backend генерирует вопросы по всему тексту заново и создаёт дубли.

## Обзор

- **«Начать» ведёт туда, где есть что повторить.** Счётчик и выбор темы считались по `dueToday`, куда входят
  и карточки «позже сегодня»: кнопка вела в тему, где повторять пока нечего. Теперь «к повторению» — это
  `dueCards` (срок уже наступил), а `dueToday` показывается подсказкой «ещё N подойдут до конца дня».
- «Повторить» на карточке темы есть, только когда в теме уже есть что повторять; «N карточек» склоняется.

## Выход

- **Кеш очищается при выходе и при ответе 401** (`useLogout`). Раньше следующий пользователь в том же браузере
  сразу видел из кеша темы и прогресс предыдущего — запросы ещё 20 секунд считались свежими.

## Ошибки и обновление данных

- **Ошибки удаления видны.** Удаление материала и карточки показывает уведомление об ошибке, удаление темы —
  ошибку в окне настроек; раньше неудача молча терялась. Уведомление об ошибке — с `role="alert"` и своей иконкой.
- **Связанные данные перечитываются.** Добавление и удаление материала обновляют единый текст, статус темы
  и список тем; удаление карточки — прогресс темы и dashboard; удаление темы — dashboard и убирает тему из кеша.
  Единый текст загружается заново при каждом открытии.

## Навигация

- `/topics/:topicId` перенаправляет на `/topics/:topicId/materials`, и вкладка «Материалы» подсвечена —
  раньше на адресе темы не была подсвечена ни одна вкладка.
- **404 по теме — «Тема не найдена»** со ссылкой на обзор вместо общего «Что-то пошло не так» без повтора.
  Ответы 4xx больше не повторяются (`createQueryClient`): от повтора они не изменятся, а экран ждал лишнюю секунду.
- **После входа пользователь возвращается на адрес, который открывал без входа** (`RequireAuth` запоминает
  адрес, `GuestOnly` возвращает на него). После «Выйти» адрес не запоминается: следующий пользователь попадает
  на свой обзор, а не на страницу предыдущего; после истечения токена — запоминается.

## Доступность

- Модальное окно закрывается по Esc, забирает фокус при открытии и возвращает его при закрытии,
  заголовок связан с окном через `aria-labelledby`.
- Карточка темы на обзоре открывается с клавиатуры: вместо `onClick` на `<article>` — растянутая ссылка
  в заголовке; кнопка «Повторить» остаётся отдельной кнопкой поверх неё.
- У иконочных кнопок (удалить, изменить тему, меню) есть `aria-label`, раскрытие ответа карточки —
  `aria-expanded`; у кнопок и ссылок есть видимый фокус с клавиатуры.

## Формы

- Поля ограничены по контракту: email 255, пароль 72 (минимум 8 — только при регистрации), тема 200/2000,
  название материала 255, ссылка YouTube 2048, текст 1 000 000 символов.
- Ссылка YouTube и название материала отправляются без пробелов по краям; ссылка из одних пробелов
  не даёт отправить форму.

## API

Без изменений: `POST /api/topics/{topicId}/questions/generate`, `GET /api/generation-jobs/{jobId}`,
`POST /api/questions/{questionId}/approve|reject`, `POST /api/questions/decisions`, `GET /api/topics/{topicId}/reviews/due`, `POST /api/topics/{topicId}/learning-sessions`,
`POST /api/cards/{cardId}/review`, `POST /api/learning-sessions/{sessionId}/complete`.

## Ошибки

| Когда | Что видит пользователь |
|---|---|
| задача генерации завершилась `ERROR` | сообщение задачи или «Не удалось создать вопросы / карточки» |
| `TOPIC_CONTENT_NOT_READY`, `NO_APPROVED_QUESTIONS` | сообщение backend над списком вопросов |
| не загрузились карточки или не стартовала сессия | «Не удалось начать обучение» и «Попробовать снова» |
| не сохранился ответ | «Ответ не сохранён: …» над кнопками, карточка остаётся |
| не сохранились итоги сессии | уведомление «Не удалось сохранить итоги сессии» |
| не удалился материал или карточка | уведомление «Не удалось удалить …: <сообщение backend>» |
| не удалилась тема | ошибка в окне настроек темы |
