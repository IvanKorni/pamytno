# 011. Расписание интервального повторения

## Правила

| Этап | Следующее повторение |
|---|---|
| 0 | сейчас |
| 1 | через 1 день |
| 2 | через 3 дня |
| 3 | через 7 дней |
| 4 | через 14 дней |
| 5 | через 30 дней |
| 6 | изучена — в очередь не попадает (`nextReviewAt = null`), но остаётся доступна |

- Новая карточка (событие `FlashcardCreated`) — этап 0, к повторению сразу.
- **REMEMBER** — этап +1 (не выше 6), `nextReviewAt` по расписанию от момента ответа, серия успехов +1.
- **FORGOT** — если этап > 1, то этап −1, иначе 0; серия сбрасывается; `nextReviewAt = сейчас` — карточка
  сразу снова в очереди и возвращается в текущую сессию. Следующий REMEMBER поднимет этап и назначит дату по
  расписанию.
- **CONTINUE** — не оценка памяти (переход к следующей части карточки): прогресс не меняется.
- Счётчики: `totalReviews`, `totalRemembered`, `totalForgotten`, `consecutiveSuccess`, `lastReviewAt`.
- Расписание изолировано в `ReviewSchedule` — позже его можно заменить на FSRS.
- `learning` хранит копию текста карточки (`card_front`, `card_back`) и обновляет её по `FlashcardUpdated`,
  чтобы показывать карточки к повторению без обращения к `deck`.

## Тесты

- Unit: `ReviewScheduleTest` (интервалы, правила этапов), `CardProgressTest` (путь 0→6 с датами, FORGOT,
  CONTINUE), `CardProgressRegistryTest` (идемпотентность).
- Модульные: `CardProgressModuleTest` — события `FlashcardCreated/Updated/Deleted` через `Scenario`.
