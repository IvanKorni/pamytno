# Правила кода

Стиль — как в `proselyte-system`: Lombok, MapStruct, OpenAPI-first, логи в квадратных скобках.
Автоматически проверяется Checkstyle (`config/checkstyle/*.xml`) и `ArchitectureRulesTest`.

## Язык

- Идентификаторы — на английском.
- Javadoc, сообщения логов, тексты ошибок API, `@DisplayName` тестов — **на русском**.

## Документация в коде

- Javadoc обязателен у **каждого** класса, record, enum, константы enum, конструктора и метода,
  включая `private` и `@Override`. Проверяет Checkstyle.
- Javadoc обязан содержать кириллицу (проверяет `ArchitectureRulesTest`).
- Первое предложение отвечает на вопрос «что делает / зачем нужен», а не пересказывает код.
- `@param`/`@return` — когда смысл неочевиден из имени.

## Размер — ничего не расползается

| Ограничение | Лимит |
|---|---|
| Длина метода | 25 строк |
| Исполняемых операторов в методе | 15 |
| Параметров метода | 5 (больше — вводи record) |
| NCSS класса / файла | 100 / 120 |
| Длина файла | 200 строк |
| Цикломатическая сложность | 6 |
| Вложенность `if` | 1 |
| Зависимостей класса (fan-out) | 15 |

Упёрся в лимит — дроби класс по ответственности (отдельный сервис на сценарий, политика, парсер),
а не ослабляй правило.

## Lombok и Spring

- Внедрение зависимостей — только через конструктор: `@RequiredArgsConstructor` + `private final`.
- `@Slf4j` для логов, `@Getter` на сущностях. `@Data` и публичные сеттеры на сущностях запрещены.
- Сущности: `protected` конструктор без аргументов, статическая фабрика `create(...)`,
  изменение состояния — доменными методами (`topic.rename(...)`, `progress.remember(now)`).
- DTO, события, value objects, настройки — `record`.
- Транзакции — на методах сервисов (`@Transactional` из Spring), не на контроллерах.

## Логи

- Формат: `log.info("Тема [{}] создана пользователем [{}]", topicId, userId)`.
- Логируем: ошибки обработки файлов и внешних API, старт/финиш AI-генерации, длительность обработки.
- Не логируем: пароли, токены, ключи API, полный текст документов.

## Именование

| Что | Шаблон |
|---|---|
| Контроллер | `<Сущность>RestControllerV1` |
| Сервис сценария | `<Действие><Сущность>Service` или `<Сущность>Service` |
| Обработчик событий | `<Событие>Listener` |
| Маппер | `<Сущность>Mapper` |
| Исключение | `<Причина>Exception` |
| Настройки | `<Модуль>Properties` |
| Миграция | `V<N>__<module>_<действие>.sql` |
