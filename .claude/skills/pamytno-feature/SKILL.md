# Фича в «Памятно»

Правила проекта — `docs/rules/*.md` (подключены в `CLAUDE.md`), они главнее этого скилла.
Здесь — порядок работы и чек-лист, чтобы не повторять договорённости из чата в чат.

## Frontend

- Фронтенд живёт в `frontend/`, использует React + TypeScript + Vite.
- Компоненты не делают `fetch`: все HTTP-вызовы находятся в `frontend/src/api/`.
- Server state хранится в TanStack Query, Zustand — только для токена, learning session и коротких UI-состояний.
- Контракты фронта следуют `openapi/*.yaml`; даты и spaced repetition рассчитывает только backend.
- Долгие операции (источники, генерация вопросов и карточек) показывают loading/success/error и опрашивают backend по id задачи.
- Unit-тесты покрывают чистые функции, module-тесты — API-слой и границы компонентов, integration-тесты — HTTP-путь с `VITE_PAMYTNO_INTEGRATION_URL`.
- `npm run check` обязателен перед коммитом; результат production-сборки не коммитится.

## Договорённости с владельцем проекта

- Стиль кода — как в проекте `proselyte-system` (эталон).
- Модульный монолит: модули **не ходят друг в друга**, только события через `common`.
- Каждый класс и метод — с Javadoc на русском. Классы и методы маленькие, ничего не расползается.
- Тесты unit + модульные + интеграционные — сразу, вместе с кодом.
- На каждую фичу и модуль — md-карточка в `docs/`.
- Коммиты маленькие и понятные, на каждое изменение.
- Правила пополняются: новая договорённость → строка в `docs/rules/` (и автопроверка, если возможно).

## 0. Разобраться

1. Раздел ТЗ в `docs/tz-backend.md`, карточка модуля `docs/modules/<module>.md`, похожая фича в `docs/features/`.
2. Модуль-владелец данных. Нужны данные другого модуля — **событие + локальная проекция**,
   никогда импорт, вызов бина или SQL к чужой схеме.

## 1. Контракт

- `openapi/<module>-api.yaml`: пути, схемы, коды ошибок (`ErrorResponse`), описания на русском.
- `./gradlew compileJava` генерирует `rest.api` / `rest.dto` — руками их не править.

## 2. Миграция

- `src/main/resources/db/migration/V<следующий>__<module>_<действие>.sql`, только схема своего модуля.
- Без FK между схемами. Закоммиченные миграции не редактировать. Пачки записей — колонка `seq`.

## 3. Домен

- Сущность наследует `common.domain.BaseEntity`, `protected` конструктор без аргументов, изменения — методами.
- Время приходит параметром `Instant now` (из `Clock` в сервисе) — домен не зовёт `now()`.
- Unit-тест на каждое правило.

## 4. Сервис и события

- Сервис на сценарий, `@Transactional`, данные всегда фильтруются по `userId`: чужое → 404.
- Исключения — наследники `common.error.*Exception` со стабильным `CODE`.
- Логи: `log.info("Тема [{}] ...", id)`; без паролей, токенов, ключей и полного текста материалов.
- Интеграционное событие — `record` в `common.event.<источник>`; приём — `@ApplicationModuleListener`.
  Одноимённые слушатели разных модулей — явное имя бина: `@Component("learningTopicDeletedListener")`.
- Долгая работа (PDF, YouTube, AI) — внутреннее событие + `@Async @TransactionalEventListener`,
  запись результата короткими транзакциями.
- Unit-тест сервиса: Mockito + `Clock.fixed(...)`, ветки успех / не найдено / конфликт / ошибка.

## 5. REST

- MapStruct: `componentModel = SPRING`, `injectionStrategy = CONSTRUCTOR`, `unmappedTargetPolicy = ERROR`.
- `<Сущность>RestControllerV1 implements <Tag>Api`, пользователь — `CurrentUser`. Контроллер не трогает репозитории.

## 6. Тесты

| Уровень | Где | Инструменты |
|---|---|---|
| unit | домен, сервисы, парсеры | JUnit 5, Mockito, AssertJ |
| модульный `<Фича>ModuleTest` | эндпоинты и слушатели модуля | `@ModuleTest`, MockMvc, `TestJwt`, `Scenario` |
| интеграционный `<Сценарий>IntegrationTest` | путь через несколько модулей | `@IntegrationTest`, `JourneyClient`, Awaitility |

- `@DisplayName` на русском, блоки `// given / // when / // then`.
- События другого модуля в модульном тесте — `scenario.publish(...)`, не его бины.
- События из асинхронных обработчиков — `CapturedEvents.await(...)` (`Scenario` их теряет).
- Время — `TestClock.advance(...)`, сброс в `@AfterEach`. YouTube — `TestWireMock`, AI — `StubAiProvider`.
- Сквозной путь ТЗ §28 — `LearningJourneyIntegrationTest`: изменил путь пользователя — дополни его.

## 7. Документация — в том же коммите

- `docs/features/<NNN>-<name>.md` (следующий номер): сценарий, API, правила и решения, ошибки, тесты.
- `docs/modules/<module>.md`: строка на каждый новый класс, таблицу, событие, эндпоинт.
- `README.md` / `.env.example` — если меняется запуск или настройки.

## 8. Проверка и коммит

```bash
./gradlew checkstyleMain checkstyleTest test          # до коммита
./gradlew moduleTest --tests '*<Фича>*'               # модульные тесты фичи
./gradlew check                                        # перед пушем: всё, включая integrationTest
```

- Упёрся в лимит Checkstyle — дроби класс или метод, правило не ослабляй.
- Коммит: Conventional Commits на русском, повелительное наклонение —
  `feat(learning): добавить прогресс темы`. Код, тесты и документация фичи — вместе.
  Рефакторинг, сборка, инфраструктура тестов — отдельными коммитами.

Для фронтенда:

```bash
cd frontend
npm run check
VITE_PAMYTNO_INTEGRATION_URL=http://localhost:8080 npm run test:integration
```

## Грабли, на которые уже наступали

- Checkstyle 14: нет `JavadocStyle`; `ApiUtil` из генератора ломал правила — генерируются только api и models.
- `Scenario` / `PublishedEvents` привязаны к потоку и теряют события из пула `@Async` — `CapturedEvents`.
- Пачка вопросов или карточек с одинаковым `created_at` приходит в случайном порядке — сортировка по `seq`.
- Массовое удаление (`delete ... where topicId`) не публикует событий по каждой записи — соседним модулям
  нужен свой слушатель исходного события (`TopicDeleted`).
- PostgreSQL в docker-compose — порт **5433** (5432 занят локальной БД).
- Ключ Anthropic — только `ANTHROPIC_API_KEY` из окружения; в тестах сеть к AI запрещена.

## Готово, когда

- [ ] контракт, миграция, код — в своём модуле, без импорта других модулей;
- [ ] Javadoc на русском у всего; лимиты Checkstyle соблюдены;
- [ ] unit + модульный (+ интеграционный, если путь через модули) тесты зелёные;
- [ ] карточки фичи и модуля обновлены;
- [ ] маленький коммит с понятным сообщением.
